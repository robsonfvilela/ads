## Aula 139: Operadores na linguagem C

### Operadores aritméticos

| Operador | Significado              |
| -------- | ------------------------ |
| *        | Multiplicação            |
| /        | Divisão                  |
| %        | Resto da divisão ("mod") |
| +        | Adição                   |
| -        | Subtração                |

> Maior precedência: *, /, %
> menor precedência: +, -

### Operadores comparativos

| Operador | Significado              |
| -------- | ------------------------ |
| <        | Menor                    |
| >        | Maior                    |
| <=       | Menor ou igual           |
| >=       | Maior ou igual           |
| ==       | igual                    |
| !=       | Diferente                |

### Operadores lógicos

| Operador | Significado              |
| -------- | ------------------------ |
| &&       | E                        |
| \|\|     | OU                       |
| !        | NÃO                      |
